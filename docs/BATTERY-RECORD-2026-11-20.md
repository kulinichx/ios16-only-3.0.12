# 时段耗电记录与首页调整

## 使用

- 越狱后进入「设置 → 时段耗电记录」。该入口与低电量计划分开。
- 设置开始、结束时间并保存，默认仅一次，可开启每天重复。结束时间小于开始时间时跨午夜。
- 「复制低电量计划时间」只复制起止时间，不复制开关，也不建立后续绑定。
- 可以不启用任何计划，直接使用「立即开始记录 / 结束当前记录」。
- 历史保留最近 60 条，点选两条查看 A/B 对照。
- 保存或手动操作后必须看到后台确认；新版本安装后需要重启 SpringBoard 才能加载新增的记录运行时代码。

## 数据与边界

记录仅在起止点读取电量、实际时间、含休眠的连续时钟、充电状态、低电量状态和系统四档热状态。不做周期轮询，也不保持多巴胺 App 在后台运行。

起点、终点均未接电、读数有效、同次启动且实际时长至少一分钟，才计算百分点/小时。电量增加、充电端点、缺失端点、重启中断或明显迟到的结果保留原始信息，不作为可比的掉电速度。

这不是逐进程能耗分析，也不证明整个时段均为锁屏待机。中途亮屏、充电、模式切换与峰值温度不在首版的观测范围内；两端状态不同会直接显示各自的值。

SpringBoard 使用一次性的 PersistentConnection 定时器，只安排下一次开始或结束；仍需 iOS 16 真机确认深度待机时的实际唤醒表现。起点晚于计划超过两分钟，或整个时段已错过，则记录「错过」而不补造数据。终点晚于计划超过两分钟标为「延迟」，显示实际采样时间。

两个计划的边界重合时，低电量开启操作在起点采样之前，终点采样在低电量关闭操作之前。记录实际读取到的低电量状态；切换失败不会冒称开启成功。记录错误不会阻断原有低电量计划。

状态文件由 SpringBoard 单独写入；App 只写独立配置和带唯一 ID、60 秒有效期的手动请求。持久化命令 ID 防止重复处理。重启或桌面重启后，未结束记录标为中断。更改系统时间或时区会中断进行中的定时记录，并按当地时间重新计算下一次计划。

## 首页

沿用 f6295a2 的正常首页尺寸与布局，移除后续增加的上下收缩及联动隐藏菜单。左右滑动仅把圆形头像及其光晕移出屏幕，同侧屏幕边缘向内拉回。隐藏状态仅在本次首页实例保留，下次冷启动重新显示圆形。

每次进程首次显示首页，短暂展示热状态。长按保留头像/温度模式选择。温度模式文字停留后渐隐，保留颜色与呼吸；返回设置或重新进入前台不重复播放开场。隐藏圆形、离开首页、后台、低电量模式或减少动态效果时停止呼吸。文字渐隐使用可取消的一次性计时器，离开页面时取消。

温度内圆使用透明渐变和羽化边缘，去掉硬质材质边框。Dopamine 标题高度由紧凑手机/普通手机/iPad 的 39/40/55 调整为 46/49/66。

## 验证范围

本地 Windows 可执行源码、配置、项目引用及模拟器脚本测试；不能运行 Xcode、UIKit 模拟器或 iOS 真机。新增的 Foundation 原生测试执行实际记录器逻辑，仅替换系统时钟、电量读取及定时器；该项需 macOS。UIKit 测试覆盖两侧隐藏/恢复、取消、短拖动、菜单保持可见和温度文字渐隐。

正式使用前至少验证：手动记录、跨午夜单次、每日计划、与低电量同一边界、锁屏后退出 App、重启中断、充电样本和两侧头像恢复。最终功耗收益与准点率以真机记录为准。
